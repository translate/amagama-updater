Amagama Updater
===============

.. note::

   Archived. amaGama's translation memory is now updated by the pipeline in
   amaGama itself: https://github.com/translate/amagama (``fetch_sources`` and
   ``update``; see its documentation on translation sources). These scripts
   were last used in 2019.

A set of scripts that allow you to pull translations from various repositories
and sources and load them into an Amagama instance.

===================
The configuration files are documented in ``conf/README.rst``
